# Infranalysis — карта доступности (Бишкек)

Интерактивная карта мест, где людям на колясках, пожилым и мамам с колясками трудно пройти:
фото, адрес, что мешает, для кого барьер, отзывы жителей и ИИ-помощник, который подсказывает, куда можно пройти.

## Как запустить

**Вариант 1 — просто открыть `index.html`** двойным кликом. Всё работает, бот отвечает по данным карты.

**Вариант 2 — с настоящим ИИ (Claude):**

```bash
npm install
```

```bash
$env:ANTHROPIC_API_KEY = "ваш-ключ"
```

```bash
npm start
```

Откройте http://localhost:8080. Без ключа сервер тоже работает — бот просто отвечает в офлайн-режиме.

В начале — выбор языка: **Кыргызча / Русский / English**. Весь сайт, интро и бот переключаются на выбранный язык;
сменить язык потом — кнопка вверху. Тексты интерфейса — в `js/i18n.js`, тексты точек — в `js/data.js`.
Сразу открыть на нужном языке: `index.html?nointro&lang=ky` (или `ru`, `en`).

После выбора языка открывается «обычный» городской портал и **ждёт**, пока вы нажмёте **«Следующий слайд ›»**
(или клавишу H / Enter / пробел / / PageDown — удобно с кликером на презентации). Все думают, что это просто
следующий слайд, — а сайт «взламывается».

Интро (обычный сайт HACKED) можно пропустить: кнопка «Пропустить», клавиша Esc или ссылка `index.html?nointro`.
Кнопка «Интро» вверху показывает его снова — удобно на защите проекта.

## Общая база в интернете (Firebase) — метки видны на всех устройствах

Без базы сайт на GitHub — просто файлы: метка с телефона сохраняется только в этом телефоне.
С Firebase метки, фото, подтверждения и отзывы хранятся в интернете и сразу видны всем.

1. Создайте проект в https://console.firebase.google.com Build **Firestore Database** Create database.
2. Project settings Your apps **Web** скопируйте `firebaseConfig` в файл `js/cloud-config.js`.
3. Firestore Database **Rules** вставьте текст из `firestore.rules` **Publish**.
4. Удалить метку: Firebase Console Firestore Database `reports` документ Delete.

В облаке проверка перед публикацией — автопроверка по правилам (ключ ИИ нельзя хранить в коде сайта).

## Метки жителей и статистика

- **«+ Сообщить о барьере»** (зелёная кнопка внизу) — любой может поставить свою метку: нажать на карту
  (или «Я здесь»), отметить, что мешает, кому мешает, и добавить фото. Метка появится со значком.
  - Через `npm start` метки и фото хранятся на сервере (`data/reports.json`, `photos/uploads/`) — их видят все.
  - На GitHub Pages / просто файлом — метка сохраняется в браузере того, кто её поставил (демо).
- **Проверка меток:** новая метка сначала «на проверке» (полупрозрачная, со счётчиком «0/2»; не попадает
  в статистику и к боту). Её должны подтвердить **2 других человека** (кнопка «Подтверждаю»; свою подтвердить
  нельзя, дважды — тоже). После 2-го подтверждения **ИИ проверяет** сообщение (с ключом — Claude, смотрит и на фото;
  без ключа — автопроверка: грубые слова, ссылки/реклама, телефоны, пустое описание). Одобрено метка «выпрыгивает»
  на карту с конфетти. Отклонено метка исчезает. Подтверждения работают через `npm start` (общий сервер):
  телефоны в той же Wi-Fi могут открыть `http://<IP-ноутбука>:8080`.
- **Статистика** (кнопка вверху) — сколько сообщений по каждому типу проблемы (нет пандуса, высокий бордюр,
  только лестница…): от волонтёров и от жителей. Нажмите на строку — карта покажет только эти места.
- Бот тоже считает: «Сколько жалоб на отсутствие пандусов?» число сообщений + кнопки к этим местам.
- Типы проблем — `PROBLEMS` в конце `js/data.js`; у каждой точки — `problems: ['noRamp', …]`.

## Как добавить свои точки после обхода

Все данные в одном файле — `js/data.js`:

1. `CITY.center` — центр района (сейчас площадь Ала-Тоо).
2. В `LOCATIONS` для каждой точки:
   - `latlng: [широта, долгота]` — правый клик по месту в 2GIS / Google Maps скопировать координаты;
   - `title`, `address`;
   - `status`: `bad` (недоступно), `mid` (есть трудности), `good` (доступно);
   - `issues` — что мешает, `good` — что хорошо, `tip` — совет;
   - `affects` — кому мешает: `wheelchair`, `elderly`, `stroller`;
   - `photo: 'photos/имя-файла.jpg'` — фото положите в папку `photos/`.
3. Примеры точек удалены — карта пустая. Добавьте свои: образец — в комментарии внутри `LOCATIONS`, или ставьте метки прямо на сайте кнопкой «+ Сообщить о барьере».

## Отзывы жителей

В демо отзывы сохраняются в браузере того, кто их написал. Чтобы все видели отзывы друг друга, нужна база данных на сервере.
